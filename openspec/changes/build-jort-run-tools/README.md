# build-jort-run-tools

Add inline invocations and deterministic built-in tools.

Implementation prerequisite: `establish-editor-ui-shell`, followed by Run history/search. Use `LinePresentationLayout` and stable `LineID` accessory anchors for controls requiring height. Canonical output retains consecutive line numbers; controls expand their anchor's band. The older fixed-height decoration language does not authorize overlapping text or introducing artificial numbered card rows.
